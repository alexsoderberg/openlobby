**Cross-cutting note (all UI requirements, REQ-0001 to REQ-0012):** the UI is English at launch, but all user-facing text must be translatable and dates and clock times must be formatted per the user's locale (vision.md DECISION). This is not a separate feature; F-026 only adds the Swedish translation.

**Cross-cutting note (mobile first):** every UI requirement is designed for phones first (under 760 px), then the desktop layout. Tap targets are at least 44 px and input text is 16 px. This is a presentation rule, not a feature (REQ-0012).
