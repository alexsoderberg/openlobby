# Feature register

The single source of truth for which functionality exists or is decided. The Service column is filled in by the architect.

| ID | Feature | Status | Service | Requirement | Comment |
|---|---|---|---|---|---|
| F-001 | Log in with Discord | Done | auth (+ gateway for session validation) | REQ-0001 | Only login method in the MVP. Manual step: live Discord login with the user's own Discord app (see REQ-0001). The logged-out landing page on `/` presents this login (design spec 2026-11-03, "Landing page"); it is a presentation, not a new feature. After login the Dashboard is at `/` and groups are reached via the Group list (REQ-0012; Amendment 2026-11-04 in REQ-0001). |
| F-002 | Create and join group via invite link | Done | calendar | REQ-0002 | Member list is shown to members. The creator becomes group admin. Members create links on request and see only their own. Links are valid for 10 minutes (fixed, Amendment 2026-11-04; was 2 hours) and always have max uses, 1–10 (default 1, Amendment 2026-11-04; was 10). Amendment 2026-11-04 (REQ-0002, REQ-0007): no invite links section in the group view; inviting is done in an invite popover from the Group rail (right-click, "Invite people") and an "Invite" button in the group view header. Unlimited links do not exist (DECISION, abuse protection). Group admins see, copy and revoke all of them (DECISION). Manual step: live test with your own Discord app and a second Discord account (create a link, join with the second account, check the member list and the 404 page after max uses). Create group is placed behind "+" in the app shell, shown only on `/groups` (REQ-0012, presentation only; Third amendment 2026-11-04). |
| F-003 | Create lobby | Done | calendar | REQ-0003, REQ-0009 | Game is chosen from the game list (F-024) or is "Other" with a free-text name. Max players is set at creation. The creator can delete their lobby. Lobby shorter than 24 hours. Amendment 2026-11-04 (REQ-0003, REQ-0004): the form opens from a "Create lobby" button and from a day in the week view; Decided, not yet built. |
| F-004 | View upcoming lobbies | Done | calendar | REQ-0004 | List sorted by start time. Shows Spot / max players (X/Y players). Per group; the cross-group view is F-028. |

Manual step: live test with your own Discord app and a second Discord account (revoke a link, then open it with the second account and check the 404 page). |

| F-030 | Game presentation: logo and accent color | Decided | – | – (REQ to be written after MVP) | Post-MVP, Could (backlog A2). **Cross-cutting note (all UI requirements, REQ-0001 to REQ-0012):** the UI is English at launch, but all user-facing text must be translatable and dates and clock times must be formatted per the user's locale (vision.md DECISION). This is not a separate feature; F-026 only adds the Swedish translation.

**Cross-cutting note (mobile first):** every UI requirement is designed for phones first (under 760 px), then the desktop layout. Tap targets are at least 44 px and input text is 16 px. This is a presentation rule, not a feature (REQ-0012).
